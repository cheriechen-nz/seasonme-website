# SeasonMe website (www.seasonmeapp.com)

Plain HTML – no build step. `index.html` (home), `privacy.html`, `support.html`, `style.css`, `images/`.

- `CNAME` tells GitHub Pages to serve the site at www.seasonmeapp.com.
- `images/` currently uses screenshots that show the sample recipe photos (placeholders).
  Before the site is promoted publicly, replace `images/` with the files in `images-no-photos/`
  (same file names), or with screenshots of your own recipes.
